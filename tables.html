Page 5 — Tables

<table>, <tr>, <th> & <td>

📝 Definition

The <table> tag creates a table. Each row is a <tr>, header cells are <th> and data cells are <td>.

⚙️ Attributes

AttributeRole
colspan (td/th)Makes a cell span several columns.
rowspan (td/th)Makes a cell span several rows.
id / classIdentifier and CSS classes for styling.

💻 Example (code)

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>20</td>
  </tr>
</table>

👀 Example (result)

NameAge
Alice20

<thead>, <tbody>, <tfoot> & <caption>

📝 Definition

These tags structure a table into header, body and footer sections. <caption> adds a title to the table.

⚙️ Attributes

AttributeRole
idUnique identifier of the section.
classCSS classes for styling the section.

💻 Example (code)

<table>
  <caption>Student grades</caption>
  <thead>
    <tr><th>Subject</th><th>Grade</th></tr>
  </thead>
  <tbody>
    <tr><td>Math</td><td>16</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Average</td><td>16</td></tr>
  </tfoot>
</table>

👀 Example (result)

Student grades
SubjectGrade
Math16
Average16
