Page 7 — Multimedia

<audio>

📝 Definition

The <audio> tag plays a sound file on the page. The <source> child tag gives the file to play.

⚙️ Attributes

AttributeRole
controlsShows the player buttons (play, volume…).
autoplayStarts playing automatically.
loopRepeats the sound forever.
src (source)Path of the audio file.

💻 Example (code)

<audio controls>
  <source src="images/song.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

👀 Example (result)

⚠️ Place a file called song.mp3 inside images/.

<video>

📝 Definition

The <video> tag plays a video on the page with a built-in player, without needing any plugin.

⚙️ Attributes

AttributeRole
controlsDisplays the player controls.
width / heightSize of the video in pixels.
posterImage shown before the video plays.
mutedPlays the video without sound.

💻 Example (code)

<video controls width="320">
  <source src="images/movie.mp4" type="video/mp4">
  Your browser does not support video.
</video>

👀 Example (result)

⚠️ Place a file called movie.mp4 inside images/.

<iframe>

📝 Definition

The <iframe> tag displays another web page inside the current page, in a small window.

⚙️ Attributes

AttributeRole
srcURL of the page to display.
width / heightSize of the frame in pixels.
titleDescription of the frame (accessibility).

💻 Example (code)

<iframe src="https://www.example.com"
        width="300" height="150" title="Example">
</iframe>

👀 Example (result)
