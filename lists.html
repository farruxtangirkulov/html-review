Page 4 — Lists

<ul> & <li>

📝 Definition

The <ul> tag creates an unordered list (bullets). Each item is written inside an <li> element.

⚙️ Attributes

AttributeRole
idUnique identifier of the list.
classCSS classes for styling.

💻 Example (code)

<ul>
  <li>Apple</li>
  <li>Banana</li>
  <li>Cherry</li>
</ul>

👀 Example (result)

  • Apple
  • Banana
  • Cherry

<ol>

📝 Definition

The <ol> tag creates an ordered list (numbered). The items are automatically numbered by the browser.

⚙️ Attributes

AttributeRole
startNumber where the list starts counting.
typeType of numbering: 1, A, a, I or i.
reversedDisplays the numbering in reverse order.

💻 Example (code)

<ol start="1" type="A">
  <li>Wake up</li>
  <li>Eat breakfast</li>
  <li>Go to school</li>
</ol>

👀 Example (result)

  1. Wake up
  2. Eat breakfast
  3. Go to school

<dl>, <dt> & <dd>

📝 Definition

The <dl> tag creates a description list. <dt> is the term and <dd> is its description.

⚙️ Attributes

AttributeRole
idUnique identifier of the element.
classCSS classes for styling.

💻 Example (code)

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

👀 Example (result)

HTML
HyperText Markup Language
CSS
Cascading Style Sheets
