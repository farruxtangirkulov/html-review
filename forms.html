Page 6 — Forms

<form>

📝 Definition

The <form> tag is a container that collects user input and can send it to a server.

⚙️ Attributes

AttributeRole
actionURL where the data is sent.
methodHTTP method used: "get" or "post".
nameName of the form.

💻 Example (code)

<form action="/save" method="post">
  <!-- inputs go here -->
</form>

👀 Example (result)

The form itself is invisible — its inputs are shown in the examples below. ⬇️

<input> & <label>

📝 Definition

The <input> tag creates interactive fields (text, checkbox, radio, etc.). <label> writes a text caption attached to an input.

⚙️ Attributes

AttributeRole
typeType of field: text, email, password, checkbox, radio…
nameName of the field sent to the server.
placeholderGrey hint text inside the field.
requiredThe field must be filled before submitting.
for (label)Links the label to the input's id.

💻 Example (code)

<label for="user">Username:</label>
<input type="text" id="user"
       name="username" placeholder="Your name">

👀 Example (result)


<textarea>, <select> & <button>

📝 Definition

<textarea> creates a multi-line text area, <select> creates a drop-down list with <option> items, and <button> creates a clickable button.

⚙️ Attributes

AttributeRole
rows / colsSize of the textarea (lines and columns).
selected (option)Pre-selects an option.
type (button)"submit", "reset" or "button".

💻 Example (code)

<textarea rows="3" cols="30">Write here...</textarea>

<select>
  <option>Red</option>
  <option selected>Green</option>
</select>

<button type="button">Click me</button>
