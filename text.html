Page 2 — Text Formatting Tags

<h1> … <h6>

📝 Definition

Heading tags define titles of different importance. <h1> is the most important, <h6> the least.

⚙️ Attributes

AttributeRole
idGives a unique identifier to the heading.
classAssigns one or more CSS classes.

💻 Example (code)

<h1>Title level 1</h1>
<h3>Title level 3</h3>
<h6>Title level 6</h6>

👀 Example (result)

Title level 1

Title level 3

Title level 6

<p>

📝 Definition

The <p> tag defines a paragraph of text. The browser automatically adds space before and after it.

⚙️ Attributes

AttributeRole
idUnique identifier of the paragraph.
classCSS classes for styling.
titleExtra information shown as a tooltip.

💻 Example (code)

<p>This is my first paragraph.</p>
<p>This is a second paragraph.</p>

👀 Example (result)

This is my first paragraph.

This is a second paragraph.

<b> & <strong>

📝 Definition

<b> makes text bold without extra importance, while <strong> marks text with strong importance (also bold).

⚙️ Attributes

AttributeRole
classCSS classes for styling.
titleTooltip text on hover.

💻 Example (code)

<b>Bold text</b>
<strong>Very important text</strong>

👀 Example (result)

Bold text
Very important text

<i>, <em> & <mark>

📝 Definition

<i> displays text in italic, <em> adds emphasis, and <mark> highlights text with a yellow background.

⚙️ Attributes

AttributeRole
classCSS classes for styling.
idUnique identifier of the element.

💻 Example (code)

<i>Italic text</i>
<em>Emphasized text</em>
<mark>Highlighted text</mark>

👀 Example (result)

Italic text — Emphasized text — Highlighted text

<br>, <hr>, <small>, <sub>, <sup>, <u>

📝 Definition

<br> makes a line break, <hr> draws a horizontal line, <small> makes text smaller, <sub> and <sup> create subscript and superscript, and <u> underlines text.

⚙️ Attributes

AttributeRole
idUnique identifier of the element.
classCSS classes for styling.

💻 Example (code)

<p>Line one<br>Line two</p>
<hr>
<p><small>Small text</small></p>
<p>H<sub>2</sub>O and X<sup>2</sup></p>
<u>Underlined text</u>

👀 Example (result)

Line one
Line two

Small text

H2O and X2

Underlined text
