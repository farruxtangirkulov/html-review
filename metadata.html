Page 9 — Metadata

What is metadata? ℹ️

Metadata is information about the page placed inside the <head>. It is not visible on the page but is used by browsers and search engines.

<title>

📝 Definition

The <title> tag sets the name of the page shown in the browser tab and in search engine results.

⚙️ Attributes

AttributeRole
—The <title> tag has no specific attributes; it only contains text.

💻 Example (code)

<head>
  <title>My Portfolio</title>
</head>

👀 Example (result)

The title appears in the browser tab — look up! ⬆️ 😄

<meta>

📝 Definition

The <meta> tag gives information about the document: character encoding, description, author, viewport settings…

⚙️ Attributes

AttributeRole
charsetDefines the character encoding (UTF-8).
nameType of metadata: description, author, viewport…
contentThe value of the metadata.

💻 Example (code)

<meta charset="UTF-8">
<meta name="description"
      content="A website to learn HTML5">
<meta name="author" content="John Doe">

👀 Example (result)

Invisible on the page! But thanks to charset="UTF-8", special characters like é, à, ñ, 🙂 display correctly.

<link>

📝 Definition

The <link> tag connects an external resource to the page — most often a CSS stylesheet. It is an empty element.

⚙️ Attributes

AttributeRole
relRelationship: "stylesheet", "icon"…
hrefPath of the external file.
typeMIME type of the file (e.g. text/css).

💻 Example (code)

<head>
  <link rel="stylesheet" href="css/style.css">
</head>

👀 Example (result)

The result is the beautiful design of this website — every page links to css/style.css with this exact tag. 🎨
