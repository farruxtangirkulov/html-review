Page 8 — Semantic and Layout Tags

What is "semantic"? 🤔

Semantic tags describe the meaning of their content (a header, a menu, an article…). They help browsers, search engines and screen readers understand the page. This very website uses them!

<header>, <nav> & <footer>

📝 Definition

<header> is the top banner of a page, <nav> contains the navigation menu links, and <footer> is the bottom section with copyright info.

⚙️ Attributes

AttributeRole
idUnique identifier of the element.
classCSS classes for styling.

💻 Example (code)

<header>
  <h1>My Website</h1>
</header>

<nav>
  <a href="index.html">Home</a>
</nav>

<footer>
  <p>© 2025</p>
</footer>

👀 Example (result)

The result is this entire website: the blue banner at the top is a <header>, the menu is a <nav> and the blue strip at the bottom is a <footer>. 🎉

<section> & <article>

📝 Definition

<section> groups content by theme, while <article> contains an independent piece of content that could stand alone (a blog post, a news card…).

⚙️ Attributes

AttributeRole
idUnique identifier (useful for anchor links).
classCSS classes for styling.

💻 Example (code)

<section>
  <h2>Latest news</h2>
  <article>
    <h3>HTML5 is awesome</h3>
    <p>Read the full story here...</p>
  </article>
</section>

👀 Example (result)

Latest news

HTML5 is awesome

Read the full story here...

<aside>, <div> & <span>

📝 Definition

<aside> is side content (sidebar). <div> is a generic block container and <span> a generic inline container — both are used for styling with CSS.

⚙️ Attributes

AttributeRole
idUnique identifier of the element.
classCSS classes for styling.

💻 Example (code)

<aside>
  <p>Sidebar content here</p>
</aside>

<p>This is <span>a special part</span> of text.</p>

👀 Example (result)

Sidebar content here

This is a special part of text.
