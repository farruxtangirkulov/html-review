This website teaches you the basic HTML5 tags. Use the menu above to navigate between the lessons. Each lesson shows the Definition, Attributes and a live Example of every tag.

<html>

📝 Definition

The <html> tag is the root element of an HTML page. It contains all the other elements of the document.

⚙️ Attributes

AttributeRole
langDefines the language of the page content (e.g. "en", "fr").
xmlnsSpecifies the XML namespace (required for XHTML documents).

💻 Example (code)

<html lang="en">
  ...
</html>

👀 Example (result)

The <html> tag wraps the whole page — the result is this very page you are reading!

<head>

📝 Definition

The <head> element contains metadata about the page (title, character set, links to CSS). It is not displayed in the browser window.

⚙️ Attributes

AttributeRole
profile(Old) Gives the URL of a metadata profile.

💻 Example (code)

<head>
  <title>My Page</title>
</head>

👀 Example (result)

The result is invisible on the page: it appears in the browser tab title.

<body>

📝 Definition

The <body> element contains all the visible content of the page: text, images, links, tables, etc.

⚙️ Attributes

AttributeRole
onloadRuns a script when the page finishes loading.
onunloadRuns a script when the user leaves the page.

💻 Example (code)

<body>
  <p>Hello world!</p>
</body>

👀 Example (result)

Hello world!
