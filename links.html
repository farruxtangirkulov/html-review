Page 3 — Links & Images

<a>

📝 Definition

The <a> (anchor) tag creates a hyperlink to another page, a website, an email address or a position inside the same page.

⚙️ Attributes

AttributeRole
hrefThe destination URL of the link.
targetWhere to open the link (_blank opens a new tab).
titleTooltip text displayed on hover.
downloadTells the browser to download the target file.

💻 Example (code)

<a href="https://www.google.com" target="_blank">
  Visit Google
</a>

👀 Example (result)

Visit Google

<img>

📝 Definition

The <img> tag displays an image on the page. It is an empty element — it has no closing tag.

⚙️ Attributes

AttributeRole
srcThe path (source) of the image file.
altAlternative text shown if the image cannot load.
widthWidth of the image in pixels.
heightHeight of the image in pixels.

💻 Example (code)

<img src="images/photo.jpg"
     alt="A beautiful landscape"
     width="300">

👀 Example (result)

⚠️ If the image doesn't appear, place a file called photo.jpg inside the images/ folder.

<figure> & <figcaption>

📝 Definition

<figure> groups an image (or diagram) with its caption. <figcaption> writes the caption text.

⚙️ Attributes

AttributeRole
idUnique identifier of the element.
classCSS classes for styling.

💻 Example (code)

<figure>
  <img src="images/photo.jpg" alt="Landscape" width="250">
  <figcaption>Fig.1 — A beautiful landscape</figcaption>
</figure>
